# Healthcare Data Analysis Using SQL

## Project Overview
This project analyses a sample healthcare dataset using Microsoft SQL Server (T-SQL). It explores patient demographics, medical conditions, medication patterns, hospital admissions, billing amounts, and length of stay.

## Skills Demonstrated
- SQL aggregations: COUNT, SUM, AVG, MIN, MAX
- GROUP BY and ORDER BY
- CASE statements and DENSE_RANK
- Window functions and common table expressions (CTEs)
- Date calculations and data interpretation

## Tools
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Project Files
- healthcare_analysis.sql: SQL queries
- dataset_profile.md: Dataset profile
- findings.md: Template for recording verified findings
- sql_review_notes.md: Review notes and limitations

## Dataset
The dataset source identified in the original project notes is:
https://www.kaggle.com/datasets/prasad22/healthcare-dataset

The raw CSV is not included. Check the dataset licence before redistribution.

## How to Run
1. Obtain the dataset from its source, subject to its licence.
2. Import it into SQL Server.
3. Check the table name and date formats.
4. Run the SQL queries and validate the results.
5. Add actual findings to findings.md.

## Limitations
This is a learning project, not a clinical decision-support system. The queries have not yet been verified through execution in SQL Server. Record counts and billing patterns do not establish hospital quality or treatment effectiveness.
