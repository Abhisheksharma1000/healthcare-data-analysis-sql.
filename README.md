# Dataset instructions

The raw CSV is not included in this public-ready package because it contains a patient-name-like field and redistribution terms have not been independently checked.

Source identified in the supplied project notes:
https://www.kaggle.com/datasets/prasad22/healthcare-dataset

Before including data:
1. Check the licence and terms.
2. Download the dataset from the original source if permitted.
3. Remove direct identifiers before publishing.
4. Never upload real patient data or confidential health records.
